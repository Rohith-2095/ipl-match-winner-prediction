# ipl-match-winner-prediction
AI Powered IPL Match Winner Prediction Dashboard using Machine Learning and Streamlit.

---

# 🚀 Features

- IPL Match Winner Prediction
- Team Winning Probability
- Real IPL Dashboard UI
- Official IPL Team Logos
- Stadium Background
- AI Prediction Engine
- Interactive UI
- Head-to-Head Analysis

---

# 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- XGBoost
- Streamlit
- Machine Learning

# ▶️ Run Project

## Install Libraries

pip install -r requirements.txt

## Train Model

python train_model.py

## Run Streamlit App

cd app

python -m streamlit run app.py
